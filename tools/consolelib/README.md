# Station console

See the [operator guide](../../docs/CONSOLE.md) for installation, station and data
configuration, peer rosters, dry runs, explicit transmission, optional witnesses,
mail credentials and shutdown. The [monitoring guide](../../docs/console-monitor.md)
covers every passive receive mode. The [HFLINK guide](../../docs/console-hflink.md)
covers ALE scanning, sounding, calls, messages and HF selcall.

The console keeps complete arm records and transcripts in the selected operator
data directory. Terminal output reports milestones; full diagnostic evidence
stays in those records. A dry run shows the proposed command without opening the
radio. Execution must be selected explicitly.
