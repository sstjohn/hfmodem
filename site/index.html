Winlink mail

Install hfmodem and exchange email

Send and receive email through a Winlink radio gateway. Use Python 3.13 on macOS or Linux. Connect the FTDX10's USB CAT and audio, or the FT-891's CAT connection and an external audio interface.

Open Terminal and paste this block
python3.13 -m venv ~/hfmodem-env
. ~/hfmodem-env/bin/activate
python3 -m pip install --pre hfmodem
hfmodem winlink

The first run guides radio, callsign, licence and audio setup, saving configuration only. Grid is optional; press Enter to skip it. Choose PACTOR-3 or VARA HF and a band your antenna is ready for, then a gateway channel. Choose to receive mail or send a text message; sending asks for a recipient, subject and message. Review the final Start this mail call? prompt. Receiving mail is the default; the hidden Winlink password is kept for this session only.

Guided calls set and check Yaesu DATA USB, the data audio route, RTS PTT and saved RF power (initially 20 W). Read the startup summary; the radio settings persist. Set CAT speed to 38400 baud and watch ALC during transmission while adjusting the provisional audio drive.

In each new Terminal, run . ~/hfmodem-env/bin/activate first. Then use hfmodem winlink pactor or hfmodem winlink vara. Add --refresh for a new gateway list. With setup saved, --dry-run previews without opening radio hardware. Ctrl-C stops the call; read its transfer and teardown results. Read saved messages offline with hfmodem winlink --inbox.

VARA chat

Chat with VarAC stations

Use hfmodem's Kestrel modem to hear CQs, call a station and exchange text. Chat is included in 0.3.0.

Terminal / from the checkout root
python3.13 -m venv ~/hfmodem-env
. ~/hfmodem-env/bin/activate
python3 -m pip install -e packages/hfhost -e packages/creance -e packages/hfmodem
hfmodem console setup --transmit
hfmodem console vara chat --band 20 --bw 500 --dry-run

Setup saves your radio, callsign, licence and audio settings without transmitting. Reuse your saved Winlink setup if you have one. Choose a band your licence and antenna support.

Review the plan, then start the session:

hfmodem console vara chat --band 20 --bw 500

This opens the radio and answers incoming calls. Check the calling frequency and watch ALC during transmission.

  1. Type /heard, then /answer N for a listed CQ. Or type /cq to call CQ on a checked slot.
  2. Once connected, type text and press Enter.
  3. Use /bye to return to monitoring or /quit to exit.

Before you start

Use Python 3.13 on macOS or Linux. Connect the FTDX10's USB CAT and audio, or the FT-891's CAT connection and external audio interface. Setup checks the system tools.

A saved receive-only station needs hfmodem console setup --replace --transmit before chat can transmit. For passive listening only, use hfmodem console vara monitor.

/status shows progress. /stop cancels an operation or aborts a link, discarding unconfirmed text.

Monitor & call

Monitor signals and make radio contacts

Start a passive decoder at the current dial, or select a frequency or saved peer. You can retune the radio while monitoring.

Terminal / passive reception
hfmodem console pactor monitor
hfmodem console rtty monitor --freq 14080
hfmodem console stanag4285 monitor --mode 1200L
hfmodem console monitor --list-modes

Frequencies are USB dial kHz in these examples. Set the radio's sideband and receive filter before starting; a wide 4 kHz voice passband is supported.
