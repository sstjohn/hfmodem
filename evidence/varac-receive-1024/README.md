# VarAC high-speed reception — 2026-10-24

Passive BW500 reception on 20 m, slot 1. The 125-second recording contains
CRC-valid L6, L7, L6 and L5 frames carrying TEXT-compressed forwarded VMail
fragments. RF endpoints are unknown. This is partial reception, not evidence
of complete-message delivery or local transmission.
